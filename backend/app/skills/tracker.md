# 기록/체크 앱 스킬

## 데이터 모양
- 날짜별 기록은 로컬 날짜 키로: `S.days = { "2026-11-19": { done: ["물"], note: "" } }`
- 항목 목록은 id를 가진 배열: `S.items = [{ id: "a1", text: "단어 50개", done: false }]`. id는 `Date.now().toString(36)`.
- 오늘 키 함수 하나를 만들어 어디서나 쓴다: `const key = d => d.getFullYear()+'-'+(d.getMonth()+1)+'-'+d.getDate();`

## 꼭 넣을 것
- 오늘 상태가 맨 위에 크게 (예: "오늘 2 / 3", 진행 바).
- 연속 기록(스트릭)은 오늘부터 하루씩 거꾸로 세되, 오늘을 아직 안 했으면 어제부터 센다.
- 이번 주 7칸 점(월~일)으로 한눈에. 오늘 칸은 테두리로 표시.
- 체크하면 `.pop` 애니메이션, 다 하면 짧은 축하 문구.
- 항목 추가는 입력칸 + 엔터. 항목 삭제는 두 번 눌러 지우기.
- seyo.widget으로 "남은 개수" 또는 "연속 일수".

## 흔한 실수
- toISOString으로 날짜 키를 만들어 한국 시간 아침에 어제로 기록되는 것.
- 날짜가 바뀌었는데 어제 체크가 오늘에 남아 있는 것 (체크 여부는 날짜 키 아래에 둔다).
