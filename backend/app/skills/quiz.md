# 퀴즈/암기 앱 스킬

## 데이터
- `S.cards = [{ id, front, back, box: 0, due: ms }]`. 사용자가 직접 추가한다 (한 줄에 "앞 - 뒤" 형식 여러 줄 붙여넣기 지원).
- 간격 반복: 맞히면 box+1, 틀리면 box=0. 다음 복습 = 지금 + [0, 1, 3, 7, 14, 30]일[box].
- 오늘 볼 카드 = due <= 지금.

## 화면
- 위: "오늘 복습 12장", 진행 바.
- 가운데 카드 하나: 누르면 뒤집힘 (CSS transform rotateY 0.3초, backface-visibility). 뒤집힌 뒤에만 "알았어요 / 몰랐어요" 버튼.
- 다 끝나면 맞힌 비율과 함께 축하 화면.
- 카드 관리(추가/지우기)는 아래 접는 영역으로, 처음엔 닫힌 상태. 카드가 0장이면 추가 영역부터 연다.
- seyo.widget('오늘 복습', 남은 장수).
