# 스타일 레시피 (국내 10~20대 여성 다꾸 감성)

사용자가 분위기를 말하면 아래에서 가장 가까운 레시피를 고르고 **끝까지 일관되게** 적용한다. 한 페이지에 테마 하나, 강조색 계열 하나, 장식 종류 2~3개까지.

| 말 | 테마 | 꼭 넣을 것 | 피할 것 |
| --- | --- | --- | --- |
| 다꾸, 감성, 파스텔, 귀엽게 | `theme-pastel` | 카드 1~2개에 `.tape`(색 다르게), 제목 옆 `.sticker` 하나, 날짜는 `.stamp`, 빈 칸은 `.paper-dot` | 진한 그림자, 원색, 큰 숫자 대시보드 |
| 키치, Y2K, 힙하게 | `theme-kitsch` | 체크 배경(테마에 있음), 검은 테두리 카드, `.sticker` 여러 개(기울기 섞기), ★♥ 같은 작은 SVG, 굵은 제목 | 세리프, 연한 회색 글씨 |
| 리본, 발레, 러블리, 레이스 | `theme-ribbon` | 세리프 제목, 리본 SVG(작은 나비 모양) 한두 개, `border:1.5px dashed var(--line)` 레이스 느낌 테두리, 넉넉한 여백 | 체크무늬, 형광색 |
| 빈티지, 레트로, 크라프트, 아날로그 | `theme-retro` | 숫자는 `.mono`, 영수증·티켓 모양 카드(점선 구분선), `.stamp`, 종이 질감 `.paper-line` | 파스텔, 둥근 알약 과다 |
| 노션, 미니멀, 깔끔, 심플 | `theme-notion` | `.cover` 띠 + 큰 제목, `.callout`, 얇은 선 표, 이모지 대신 작은 SVG 아이콘 | 그라데이션, 기울기, 스티커 |
| iOS, 아이폰, 애플처럼 | `theme-ios` | 회색 배경 위 흰 둥근 그룹 목록, 큰 굵은 제목, 파란 강조 | 장식, 테이프 |
| 다크, 어두운, 검정 | `theme-dark` | 대비 충분한 글자, 강조는 한 색만 빛나게 | 순검정 위 회색 글씨(안 보임) |
| 모눈, 공부노트, 필기 | `theme-grid` 또는 `.paper-grid` | 손으로 쓴 노트 같은 배치, `.mark` 형광펜 | 카드 그림자 과다 |

색 이름만 말하면(핑크로, 하늘색으로) 테마를 바꾸지 말고 `:root{--accent:..;--accent-soft:..}`와 `--bg`만 바꾼다.

## 다꾸 장식 쓰는 법 (과하면 촌스럽다)
- 마스킹테이프: 카드 위쪽 가장자리에 걸치게. 한 화면에 2~3개, 서로 다른 색·각도.
- 스티커: 카드 모서리에 살짝 겹치게(`position:absolute; top:-10px; right:12px`). 글자는 짧게("D-7", "오늘!", "♡").
- 폴라로이드: 사진 자리나 대표 이미지. `.tilt-l`/`.tilt-r`로 살짝 기울여 두 장이면 서로 반대로.
- 작은 SVG 두들(별, 하트, 반짝이, 구름, 리본): 제목 옆이나 빈 구석에 1~3개. 16~28px, 강조색. 이모지 도배 대신 이걸 쓴다.
- 손글씨 폰트는 없다(인터넷 차단). 대신 `.title-serif`, 굵기 대비, `letter-spacing`으로 표정을 낸다.
- 장식은 내용 위를 가리지 않게 `pointer-events:none`.

## 레이아웃 기본기
- 위계: 큰 제목 1개 → 섹션 제목(13~15px, 굵게) → 본문. 숫자 대시보드 카드를 습관처럼 맨 위에 두지 않는다. 필요한 숫자만 작게.
- 속지 느낌: 화면을 "한 장의 종이"처럼. 카드를 줄줄이 쌓기보다, 큰 종이 한 장(`.card` + 종이 질감) 안에 영역을 나누는 편이 다꾸답다.
- 여백: 카드 안 20~28px, 섹션 사이 24~32px. 빽빽하면 고급스럽지 않다.
