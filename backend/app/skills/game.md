# 게임/성장 앱 스킬

공부를 하면 무언가가 자라는 앱. 재미가 핵심이지만 결국 공부 기록 앱이다.

## 규칙
- 경험치는 실제 행동(공부 시간 입력, 할 일 체크)에서만 생긴다. 누르기만 하면 오르는 버튼 금지.
- 레벨 곡선: 레벨 n이 되려면 `need(n) = 50 + (n-1) * 30` 경험치. 남은 경험치를 진행 바로.
- 저장: `S = { xp, level, log: [{ at, what, xp }] }`. 레벨은 xp에서 다시 계산할 수 있게.

## 캐릭터
- 인라인 SVG로 단순하고 귀엽게: 둥근 몸, 눈 두 개, 볼터치. 레벨에 따라 크기, 색, 소품(새싹 → 잎 → 꽃, 또는 모자/왕관)이 바뀐다.
- 가만히 있을 때 2~3초 주기로 살짝 위아래로 움직이는 숨쉬기 애니메이션.
- 경험치를 얻으면 `+15` 숫자가 위로 떠오르며 사라진다. 레벨업이면 캐릭터가 통통 튀고 색종이(작은 div 20개)가 0.8초 흩어진다.

## 화면
- 위: 캐릭터(가장 크게) + 이름 + "Lv.3". 그 아래 경험치 바와 "다음 레벨까지 40".
- 가운데: 기록 입력 (예: 공부 시간 칩 15분/30분/1시간 + 과목 칩).
- 아래: 오늘 기록 목록.
- seyo.widget('레벨', level).
