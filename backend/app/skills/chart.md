# 그래프/통계 앱 스킬

라이브러리가 없으니 그래프는 인라인 SVG로 직접 그린다.

## 그리기
- `viewBox="0 0 W H"`와 `width="100%"`로 반응형. 좌표 변환 함수 `x(i)`, `y(v)`를 먼저 만든다.
- 막대: 둥근 위 모서리(rx=4), 가장 최근/오늘 막대만 `--accent`, 나머지 `--line`보다 조금 진한 회색.
- 꺾은선: 2.5px 선 + 마지막 점만 동그라미와 값 라벨.
- 축은 최소한: 바닥 선 하나와 아래 라벨(요일, 날짜, 회차). 격자선은 아주 옅게 2~3개.
- 값이 하나도 없으면 그래프 대신 `.empty` 안내.
- 숫자는 `toLocaleString('ko-KR')`, 평균, 최고, 지난번 대비(+3점, 초록/빨강)를 위에 요약.

## 데이터
- 입력은 앱 안에서 직접: 날짜 + 값(+ 과목) 폼. `S.points = [{ date: "2026-11-19", v: 82, tag: "수학" }]`.
- 과목/태그별로 칩으로 걸러 보기.
